What is SELECT?
In SQL SELECT helps to specify which records and columns we need to find, display or edit.

## SELECT - Functionalities  
| Command   | How it works | JOIN Types | How it works |
|-----------|--------------|------------|--------------|
| ORDER BY  | Groups target data in groups or categories. | INNER JOIN | Returns only the rows that have matching values in both tables. |
| GROUP BY  | Sorts the data that you retrieve in an order of your choosing | LEFT JOIN | Returns all rows from the left table, and the matched rows from the right table (or NULL if there is no match). |
| LIMIT     | Specifies the number of records a query should return after filtering data | RIGHT JOIN| Returns all rows from the right table, and the matched rows from the left table (or NULL if there is no match). |
